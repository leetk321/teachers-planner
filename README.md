# 디지털 교무수첩 (Teachers Planner)

교사의 학생 관리, 상담 기록, 사안 관리, 출석 메모, 일정, 메모와 전달사항을 위한 웹 애플리케이션입니다.

이 저장소는 v3.16.0 실행 소스를 기준으로 정리한 GitHub 배포용 복사본입니다. 운영 데이터와 인증키는 포함하지 않습니다.

## 구성

- `apps/web`: Next.js / React 프런트엔드
- `apps/api`: Express API, SQLite 저장소, 마이그레이션과 검증 도구
- `scripts`: 배포 및 검증 스크립트
- `DEPLOY_SYNOLOGY.md`: NAS 배포 안내
- `RELEASE_v3.16.0.md`: 버전 변경 내용

## 로컬 실행

Node.js 20 환경에서 각 앱의 잠금 파일을 사용해 의존성을 설치합니다.

```sh
cd apps/api
npm ci
npm start
```

별도 터미널에서 웹을 실행합니다.

```sh
cd apps/web
npm ci
npm run dev
```

웹 기본 주소는 `http://localhost:3000`, API 기본 주소는 `http://localhost:4000`입니다. 외부 서비스 없이도 실행할 수 있으나 급식, 날씨, 시간표, Google 연동 등은 별도 설정이 필요합니다. 학교와 교사 정보는 로그인 후 설정에서 입력합니다.

## NAS 배포

`.env.synology.example`을 참고하여 별도의 `.env`를 구성하고 배포 안내를 따르세요. 예시 도메인은 실제 웹/API 주소로 변경해야 합니다. API 인증키는 서버 환경변수 또는 앱의 설정으로 관리하고 저장소에 커밋하지 마세요.

기존 설치의 DB, 사진, 첨부파일 볼륨은 그대로 유지해야 합니다. 이 저장소를 복사하면서 운영 데이터 폴더를 삭제하거나 빈 폴더로 덮어쓰지 마세요.

## 공개용 정리 사항

- 운영 DB, 학생 사진, 첨부파일, 백업, 과거 스냅샷과 ZIP을 제외했습니다.
- `node_modules`, `.next`, 일회성 수정 스크립트를 제외했습니다.
- 특정 학교와 교사 기본값을 비웠고 운영 도메인을 예시로 변경했습니다.
- 현재 코드에서 참조하지 않는 파일 아이콘 스프라이트 2개는 출처 확인이 필요하여 제외했습니다. 실행 화면은 기존 이모지 기반 아이콘을 사용합니다.
- 원본의 버전과 패치노트는 유지했습니다.

## 검증과 보안

API 의존성을 설치한 뒤 `apps/api`에서 `npm run db:verify`로 마이그레이션을 검증할 수 있습니다. 운영 서버를 대상으로 하는 smoke test는 테스트 계정을 생성할 수 있으므로 격리된 테스트 환경에서만 실행하세요.

`.gitignore`는 실수로 파일을 추가하는 위험을 줄일 뿐 비밀값 검사를 대신하지 않습니다. 커밋 전 변경 파일을 검토하고 실제 인증키와 학생 정보를 포함하지 않았는지 확인하세요. 과거 배포본에 포함되었던 인증키는 별도로 재발급하는 것이 좋습니다.

## 라이선스

프로젝트 라이선스는 아직 지정하지 않았습니다. 이 복사본을 준비하면서 임의로 오픈소스 이용 권한을 부여하지 않았습니다. 공개 배포 전 소유자가 라이선스를 결정하고, 포함된 외부 의존성의 라이선스도 확인해야 합니다.
